## BLOCK 5 — HOW I WORK

**Section heading:**
How I work.

> Three-step process. Strong candidate for the visual "terminal / node-flow" treatment (see visual identity doc). diagnose → build → refine.

### Step 1 — Diagnose
I start by talking to your team: what problems they're running into, where they lose time, and how the process actually works today. No building until I understand the mess.

### Step 2 — Build
I design and set up the system: CRM, automations, integrations, processes. Everything gets documented, so it keeps working without me.

### Step 3 — Refine
I analyze the results, see what's working and what isn't, and figure out what to build next. A system is never really finished.

## NOTES FOR DESIGN

- PPC is part of the broad base only — don't feature it more prominently than automation/systems, which is the core positioning.
- This page leans on capabilities + two testimonials, not on client logos or big metrics (none yet). Don't build empty "as seen in / trusted by" logo strips — it highlights what's missing.
- Block 5 (How I work) is the best place to show the brand's systems aesthetic in action.
- If a metric anchor is added later (e.g. an A/B test conversion lift), the testimonials block is where it fits best.
